## Project Description
A command-line to-do list application built with Python demonstrating variables, collections, control flow, iteration, and user interaction.

## Features
- **Add Task:** Create new tasks with descriptions
- **View Tasks:** Display all tasks with completion status (✓ DONE or ○ TODO)
- **Mark Complete:** Update task status to completed
- **Delete Task:** Remove tasks from the list
- **Exit:** Safely close the application

## Technologies Used
- Python 3.x
- Git for version control
- GitHub for repository hosting

## How to Run
1. Clone this repository or download the files
2. Open terminal in the project folder
3. Run: `python todo_app.py`
4. Follow the on-screen menu prompts

## Course Concepts Demonstrated
- **Variables & Data Types:** Strings for task descriptions, booleans for completion status
- **Collections:** List of dictionaries to store task data
- **Control Flow:** if/elif/else statements for menu navigation
- **Iteration:** for loops to display tasks with enumerate()
- **User Interaction:** input() for menu choices and task entry
- **Functions:** Modular design with separate functions for each feature
